# Installation    
Note that this is only tested on chrome, bugs on other platforms are expected.    
Clone the repo into a folder, ensure that chrome's dev mod is on, head to extensions and click "Load unpacked", selecting the folder you cloned the repo to.    
Alternatively (recomended) download the latest releases ZIP file, unzip it and load it like the above.    

# Usage
On clicking the extension, you will be shown a checklist of all your tabs. Select upto 4 to open a duo/quad tile (I'll call this a tiled tab for now)!    
Clicking the extension while on a tiled tab will show you controls that you would normally see, incl back/forward/reload buttons, close buttons, and an Extract button, which will popout one of the tiles as a normal tab again!    
The text box can either take a URL which you can load by pressing "load" (duh) or a search query by pressing the search icon!    
Clicking the dashboard will take you to the dashboard (cool right?) where you can read any comments ive left and change settings. Currently, there are 3 settings.    
  using Hide scrollbars is self explanatory
  using autozoom will set the zoom to 50% or 25% by default (depends on if you are on a duo or quad tile)

You can also reload previously saved layouts! (incase you made a daily review layout with ur teams outlook company portal and slack idk)
