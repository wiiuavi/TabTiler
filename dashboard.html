Important Notes & Limitations

⚠️ Tab Reloading: When converting a standard tab into a tile layout pane, the page reloads inside an iframe. Unsaved input data will be lost.
⚠️ Cross-Origin Restrictions: Dragging text or files directly between tiles of different websites is blocked by browser security rules.

How to Extract: Use the ⏏ (Extract) button in the popup control card to convert an iframe tile back into a regular browser tab.
